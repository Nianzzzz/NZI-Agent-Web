# /verify - 验证构建

运行全面验证，确保代码质量。

## 执行步骤
1. 运行 `npm run build` — 验证构建
2. 运行 `tsc --noEmit` — 验证类型
3. 运行 `npm run lint` — 验证 Lint
4. 运行 `npm run test` — 验证测试
5. 运行 `npm audit` — 验证依赖安全
6. 输出验证报告

## 验证清单
- [ ] 构建成功
- [ ] 类型检查通过
- [ ] Lint 通过
- [ ] 测试通过
- [ ] 安全审计通过
- [ ] 文档已更新

## 人类确认点
验证不通过时，必须修复后重新验证。
