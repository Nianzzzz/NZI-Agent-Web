# /spec - 生成规范文档

基于当前需求，生成规范文档到 `docs/specs/`。

## 执行步骤
1. 读取相关 ADR 和知识库
2. 使用 brainstorm 技能澄清需求（如需要）
3. 生成规范文档，包含：
   - 功能描述
   - 技术方案
   - API 契约
   - 数据模型
   - 验收标准
4. 等待人类确认

## 输出格式
```markdown
# [功能名称] 规范

## 1. 功能描述
[描述]

## 2. 技术方案
[方案]

## 3. API 契约
[OpenAPI/JSON Schema]

## 4. 数据模型
[Prisma Schema]

## 5. 验收标准
- [ ] 标准 1
- [ ] 标准 2

## 6. 风险与缓解
| 风险 | 影响 | 缓解措施 |
|------|------|----------|
```

## 人类确认点
规范文档生成后，必须等待人类确认才能进入计划阶段。
