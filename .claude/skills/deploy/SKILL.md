# 部署技能

## 触发场景
- 部署到生产环境
- 配置 CI/CD 流水线
- 设置监控和告警

## 执行流程

### 阶段1: 部署前检查
1. 所有测试通过
2. 代码审查通过
3. 安全审计通过
4. 文档已更新

### 阶段2: 执行部署
1. 构建 Docker 镜像
2. 推送镜像到仓库
3. 更新 Kubernetes 配置
4. 执行滚动更新

### 阶段3: 部署后验证
1. 健康检查
2. 冒烟测试
3. 监控指标

## 约束
- 必须通过所有验证才能部署
- 部署后必须执行冒烟测试
- 必须有回滚方案
