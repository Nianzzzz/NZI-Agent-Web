# 学习技能

## 触发场景
- 会话结束时
- 代码审查发现新问题时
- 解决复杂问题后

## 执行流程

### 阶段1: 提取模式
从当前会话中提取：
1. 可复用的代码模式
2. 常见陷阱和解决方案
3. 最佳实践

### 阶段2: 更新知识库
1. 更新 `docs/knowledge/patterns.md`
2. 更新 `docs/knowledge/pitfalls.md`
3. 更新 CLAUDE.md（如有新规范）

### 阶段3: 输出学习报告
- 本次会话学到的新模式
- 更新的文件列表
- 下次需要注意的点

## 约束
- 使用 haiku 模型节省 Token
- 只提取可复用的模式，不记录一次性问题
- 保持知识库简洁，定期清理过时内容
